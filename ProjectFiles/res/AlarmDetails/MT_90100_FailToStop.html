Alarm Response Plan

Tag: MT-90100 — Compressor Motor Failed to Stop

1. Alarm Summary

Alarm TagMT-90100.FailToStop
EquipmentCompressor Motor MT-90100
Alarm DescriptionMotor run feedback remained ON after a stop command and the configured stop timer expired
PriorityCRITICAL
Alarm ClassSafety / Loss of Control
Response TimeImmediate (< 2 minutes)
Consequence of InactionLoss of remote stop capability, potential inability to safely shut down the compressor, downstream over-pressure or equipment damage

2. Possible Causes

  • Welded / stuck contactor in the MCC bucket.
  • Drive not accepting stop command (comm loss, hardwired run signal energized).
  • Run feedback stuck ON (bad aux contact, shorted wiring).
  • Motor being back-driven by process (windmilling) creating apparent run feedback via reverse-current relay.
  • Local override / hand switch left in RUN position at the MCC.
Safety Notice: Treat this as a loss-of-control event. If the motor is genuinely still running and cannot be stopped remotely, use the field E-Stop or open the upstream breaker per site LOTO procedure. Notify the Shift Supervisor immediately.

3. Operator Response Actions

  1. Acknowledge the alarm and immediately notify the Shift Supervisor.
  2. Confirm actual motor state — is the compressor still turning? Check discharge pressure/flow trend.
  3. If motor is still running and cannot be stopped from HMI: dispatch operator to trip the field E-Stop or open the upstream breaker.
  4. If motor is actually stopped (only feedback stuck), isolate downstream and place system in safe state until IO fault confirmed.
  5. Place downstream users of MT-90100 in a safe state and depressurize as required.

4. Troubleshooting Guidance

  1. Verify Local/Remote selector position at the MCC.
  2. Physically inspect the contactor for welded contacts — DO NOT open the bucket without LOTO.
  3. Verify run feedback wiring and aux contact operation.
  4. Check for backspin from the process gas that could hold the motor rotating after power removal.
  5. If VFD, check drive parameter for coast vs ramp-to-stop configuration.
Note: After a welded contactor event, the MCC bucket must be replaced or refurbished before the motor is returned to service.

5. Reset and Restart Criteria

  • Motor confirmed stopped by field verification.
  • Root cause identified and repaired (contactor replaced, wiring corrected, drive verified).
  • Bump test confirms motor starts and stops on remote command with matching feedback.
  • Shift Supervisor and Maintenance sign-off documented.
  • Reset alarm at MT-90100 faceplate.
