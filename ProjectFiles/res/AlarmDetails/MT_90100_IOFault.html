Alarm Response Plan

Tag: MT-90100 — Compressor Motor IO Fault

1. Alarm Summary

Alarm TagMT-90100.IOFault
EquipmentCompressor Motor MT-90100
Alarm DescriptionLoss or bad quality of one or more IO signals associated with MT-90100 (control output, run feedback, or auxiliary contact)
PriorityHIGH
Alarm ClassInstrument / Control System Integrity
Response TimeImmediate (< 5 minutes)
Consequence of InactionUnreliable motor state, possible spurious trip or failure to trip on demand, loss of interlock protection

2. Possible Causes

  • IO module fault or bad module status (channel diagnostic bit set).
  • Broken or loose field wiring on run command, run feedback, or aux contact.
  • Blown fuse on 24 VDC or 120 VAC IO power supply.
  • Communication loss to the remote IO chassis / adapter.
  • Configuration mismatch after recent PLC/IO change.
Safety Notice: While this alarm is active, the motor's protective interlocks may be degraded. Do NOT bypass the alarm. If the motor is running, prepare for a controlled shutdown until the IO signal is restored.

3. Operator Response Actions

  1. Acknowledge the alarm and note the time.
  2. Open the MT-90100 faceplate and identify which IO point is faulted (Run Cmd / Run Fbk / Aux / IO Module status).
  3. Verify the motor's true running state via local indication or field walk-down.
  4. If motor is running and feedback is lost, plan a controlled shutdown — do NOT rely on remote stop.
  5. Place downstream users in a safe state or switch to spare unit MT-90101 if available.
  6. Notify the Shift Supervisor and Instrument/Electrical technician.

4. Troubleshooting Guidance

  1. Check IO module status LEDs in the field cabinet and PLC diagnostic tag.
  2. Verify 24 VDC / 120 VAC field power to the affected IO channel.
  3. Inspect field wiring at motor starter / MCC bucket and terminal blocks.
  4. Check for recent PLC download or IO configuration change — roll back if suspected.
  5. If remote IO comm loss, verify network switches, EtherNet/IP path, and adapter status.
Note: If the fault is only on the Run Feedback, the motor may still be operable in manual with supervisor approval, but interlock coverage is reduced — keep an operator at the MCC.

5. Reset and Restart Criteria

  • IO fault bit cleared and channel returned to Good quality.
  • Field walk-down complete, wiring verified.
  • Run feedback matches commanded state during a bump test.
  • Shift Supervisor approval logged.
  • Reset MT-90100 faceplate alarm and resume normal operation.
