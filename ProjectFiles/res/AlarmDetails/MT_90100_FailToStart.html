Alarm Response Plan

Tag: MT-90100 — Compressor Motor Failed to Start

1. Alarm Summary

Alarm TagMT-90100.FailToStart
EquipmentCompressor Motor MT-90100
Alarm DescriptionMotor did not achieve running feedback within the configured start timer after a start command
PriorityHIGH
Alarm ClassEquipment Availability
Response TimeImmediate (< 5 minutes)
Consequence of InactionLoss of process availability, possible starter damage from repeated start attempts

2. Possible Causes

  • Permissive not satisfied (lube oil pressure, cooling water, seal gas, standstill).
  • Interlock trip active or not reset (High Oil Temp, High Current, High Vibration).
  • Loss of control voltage to the MCC bucket or drive.
  • Overload relay tripped or MCC breaker open.
  • Bad run feedback signal (motor is actually running but feedback missing).
  • Local / Remote selector in wrong position.
  • Anti-restart timer / minimum-off timer still active.
Safety Notice: Do NOT repeatedly cycle the start command. Repeated failed starts can overheat motor windings and damage the starter. Limit to two attempts before troubleshooting.

3. Operator Response Actions

  1. Acknowledge the alarm and record the time.
  2. Open MT-90100 faceplate – review Permissive and Interlock status; identify any that are NOT satisfied.
  3. Confirm motor is actually stopped (no run indication, no discharge pressure rise).
  4. Reset any latched interlock trips and clear the failure alarm before re-attempting.
  5. If all permissives are satisfied, attempt one more start under supervisor approval.
  6. If the second attempt fails, do not try again — dispatch maintenance.

4. Troubleshooting Guidance

  1. At the MCC, verify control voltage, overload relay state, and breaker position.
  2. Check drive/starter for latched fault codes (see MT_90100_DriveFault plan if VFD).
  3. Verify Local/Remote selector in Remote and E-Stop reset.
  4. Verify all field permissive transmitters are reading correctly.
  5. Confirm run feedback wiring – bump test the aux contact.
  6. Review start timer setting – ensure it is not shorter than motor acceleration time.
Note: On large compressor motors, verify the motor has fully coasted to a stop and any anti-restart / thermal restart delay has expired before re-attempting a start.

5. Reset and Restart Criteria

  • Root cause of failure identified.
  • All permissives satisfied and interlocks reset.
  • Motor thermal state acceptable (winding temperature within limits).
  • Shift Supervisor approval to attempt restart.
  • Clear the FailToStart alarm at the faceplate and issue a new start command.
